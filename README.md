# EasyLift

**Less waiting. More lifting.**

A gym app that shows equipment availability and recommends the best time to work out. Built as an MVP for CS 420.

> All gym data is simulated. Plans, reports, and feedback are saved in your browser only and aren't shared with other users.

## Run locally

Requires Node.js 22.12 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Import this repo into [Vercel](https://vercel.com/new) and click **Deploy**. No environment variables needed.
